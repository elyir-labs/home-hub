## What's new

- Play music on a speaker from its card, or in several rooms at once, all in step.
- A hub with no cable can be set up from a phone: it makes a Wi-Fi of its own until it's on yours.
- A second screen on the wall now keeps itself up to date with the hub.

## Details

- The hub works out what the computer it runs on can do, and offers only that.
- A hub started from a USB stick on a mini PC moves onto the computer's own drive, and asks first if
  that drive has anything on it.
- A Raspberry Pi set up from the hub's download shows Elyir's startup and then the house on any screen
  plugged into it.
- A Raspberry Pi now starts from a USB stick before its memory card, so it can be set up again without
  opening it.
