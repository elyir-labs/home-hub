One way in, four beats, every time.

Adding a thing is always the same four screens in the same order, with the same words on the buttons. Only the second beat differs, and it differs because the object differs — some things blink, some have a code, some want signing in to. That is the only variation the house is allowed.

beat one
What have you got?
Four answers a person can give without knowing a single thing about radios. Anything already waiting sits above them.
beat two
Which one is yours?
The only beat that changes shape. Never a protocol on screen — the proof is the object: it blinks, it is held, it is signed in to.
beat three
Letting it in.
One bar, one plain sentence about what is happening, one honest how‑long. Walking away never breaks it.
beat four
It’s in. Which room?
What it turned out to be, in objects. Then the room, asked once, every route, while somebody is still standing there.
