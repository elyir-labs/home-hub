How the house tells them apart — and the field this board used to name, which does not work

This board once said every Matter device announces a vendor and a product id, so the house could recognize one of ours whoever set it up. The first real commissioning reported TEST_VENDOR and TEST_PRODUCT — esp‑matter’s defaults on a test vendor id, identical on every device built this way. Until a real Vendor ID exists it is our own mDNS service that answers this, and that is the same service which carries the handshake — so the offer in column two appears only for a strip that could take it. The test never changed: has this strip ever completed our handshake?
