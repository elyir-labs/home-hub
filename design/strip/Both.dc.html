What actually decides, and it is not a setting

The first session to complete takes it, and the strip then stops offering the other door. Not the first to connect — a half‑finished attempt from either side must leave the strip exactly as it found it, because the commonest real event here is somebody starting in the wrong app and giving up. No screen asks which protocol this household has, because no household knows.
