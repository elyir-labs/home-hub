Today · how a hub is set up now

A box with no screen starts with a cable to the router.

Traced from install.sh, the Pi image’s README and today’s NUC install. Three of the five steps happen before the household sees a single word from us, and two of them need things a home may not have.

1 · Put the hub on it
A borrowed keyboard and monitor

A NUC: write Ubuntu to a USB stick, install it, then paste the install command. A Pi: flash our image.

Nobody we are building for owns a spare monitor, or will type a command.
2 · A cable to the router
Next to the router, on a free port

The hub has no Wi‑Fi until someone gives it one, and with no screen there is nowhere to type it.

Routers live in closets, mesh pucks have one port or none, and the hub ends up where the cable reaches.
3 · Wait
The first start downloads the house

The engine and the brain are pulled from the internet on first boot. Nothing on the box says how far along it is.

4 · Find it
Type hub.local, and hope

On a phone or a laptop on the same network, once it is ready, which you find out by trying.

Some phones and routers never answer a .local name. Two hubs on one network can't both have it.
5 · Welcome home.
The first thing we wrote

Setup proper: names, a passcode, where home is, rooms. This part is drawn already, in design/setup/ and design/words-setup/, and is not what this collection changes.

Both directions keep step 5 as it is, and remove 1 to 4: the box arrives with the hub on it the house is already downloaded no cable, anywhere in the house a phone finds it, not a typed name
